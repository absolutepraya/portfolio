# Microsoft Azure Icon Reference

This directory contains the complete Microsoft Azure Architecture Icons V24 pack downloaded on 2026-08-01 from the official Microsoft distribution:

`https://arch-center.azureedge.net/icons/Azure_Public_Service_Icons_V24.zip`

The downloaded ZIP is retained unchanged as `Azure_Public_Service_Icons_V24.zip`; its extracted contents are in `pack/`. Two SVGs have only terminal whitespace normalized in the extracted copy so repository diff validation remains clean.

`CATALOG.txt` lists all 714 SVG paths in the pack, sorted alphabetically. Use it to locate a service icon before copying only the needed SVG into `src/assets/stacks/azure/`. Files here are reference material and are not imported by the application, so they are not included in the production portfolio build.

For use terms and guidance, read the included `Azure_Icons_FAQ.pdf` and the [Microsoft Azure Architecture Icons documentation](https://learn.microsoft.com/en-us/azure/architecture/icons/).
