# Portfolio Experience

This context defines the vocabulary for the portfolio's experience section and its recruiter-facing presentation.

## Experience presentation

**Experience entry**:
 A role at an organization with its date, description, visual identity, organization link, and optional earlier roles.

**Role header**:
 The always-visible part of an experience entry that identifies the role, organization, date, logo, and disclosure control.
 _Avoid_: summary card, teaser

**Role details**:
 The existing Markdown description and earlier-role information belonging to an experience entry.
 _Avoid_: rewritten copy, generated summary

**Compact disclosure timeline**:
 The presentation where all role headers remain scannable in a vertical timeline and each entry reveals its existing role details on demand.
 _Avoid_: stacked experience cards, experience carousel

**Role disclosure**:
 The interaction that opens one experience entry's existing details from its compact role header.
 _Avoid_: global Show More, modal details

**Description disclosure**:
 The existing gradient fade and “Read more” interaction that reveals the complete Markdown description when it is longer than the collapsed height.
 _Avoid_: rewritten preview, truncated copy

**Compact role header**:
 The three-zone layout with date, existing role and organization content, and the existing chevron; on mobile, the same information stacks naturally.
 _Avoid_: condensed card copy, horizontal carousel

**Organization link**:
 The existing link from an organization's name to its external website. It remains a normal link while the role area and chevron control role disclosure independently.
 _Avoid_: nested link button

**Decorative organization label**:
 The large faded organization name currently shown above an experience card, retained for expanded entries only.
 _Avoid_: repeated label on every compact row

**Existing visual system**:
 The portfolio's established fonts, colors, icons, logos, borders, Markdown treatment, and motion language. Layout changes preserve this system.
 _Avoid_: visual redesign, style refresh
